# Cloudalign Surveyor - Technical Architecture

## Overview
Digital site assessment platform designed to standardize technical surveys, site assessments, and design readiness evaluations.

## Technology Stack
- Frontend:** Next.js (TypeScript, Tailwind CSS)
- Backend:** Node.js / ASP.NET Core
- Database:** PostgreSQL (Supabase / Neon Free Tier / Local Docker)
- Authentication:** Microsoft Entra ID (Free Tier - Up to 50,000 MAU) / OAuth 2.0
- Storage:** Azure Blob Storage (5 GB Free Tier / Azurite Local Emulator)

## Core User Roles
- Administrator
- Project Manager
- Surveyor
- Engineer
- Reviewer
- Approver
- Collaborator
